# Godot Cheat Sheets
Unless otherwise noted, all files for Godot 4.4, as of 5/3/2025.

Files:

- **Godot 4.4 Default Key Mappings.xlsx**
	- Default key mappings from the official [Default editor shortcuts](https://docs.godotengine.org/en/stable/tutorials/editor/default_key_mapping.html).
	- Microsoft Excel format.
- **Godot 4.4 Key Mappings.afpub**
	- Default key mappings cheat sheet.
	- Designed in Affinity Publisher 2.
- **Godot 4.4 Key Mappings.pdf**
	- Latest file in PDF format.
- **Godot 4.4 Key Mappings.png**
	- Latest file in PNG format.
